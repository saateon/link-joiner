# عیب‌یابی

## پنجره بسته می‌شود
اسکریپت با `pause` تمام می‌شود. اگر باز هم بسته شد، `join-links.cmd` را از Command Prompt اجرا کن.

## خطای «File not found»
مسیر فایل را بررسی کن. اگر مسیر فاصله دارد، آن را داخل گیومه بگذار:
```
join-links.cmd "C:\My Files\links.txt"
```

## خطای «The file has no text»
فایل خالی است. لینک‌ها را بنویس و ذخیره کن.

## خطای ExecutionPolicy
راه‌انداز `.cmd` این مشکل را دور می‌زند. فقط از `join-links.cmd` اجرا کن.

## حروف فارسی خراب شد
فایل ورودی را با کدگذاری UTF-8 ذخیره کن. خروجی همیشه UTF-8 است.

## Set-Clipboard کار نمی‌کند
گزینه‌ی `-NoClipboard` را بزن. خروجی در فایل ذخیره می‌شود.
